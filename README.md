### Projects
**note**: these are hosted on my private forgejo instance. To get access, see [https://www.abrhoda.com](https://www.abrhoda.com/about/#repositories).

- [geo](https://git.abrhoda.com/abrhoda/geo) - a c99 single header 2d geometry library that handles points, geometries, and calculautions.
- [llog](https://git.abrhoda.com/abrhoda/llog) - a c99 "little log" library for writing logs to files with configurable size and time based rotation policies.
- [unorderedmap](https://git.abrhoda.com/abrhoda/unorderedmap) - a c99 hash map implementation that makes the same guarantees as c++'s `std::unorderedmap`.
